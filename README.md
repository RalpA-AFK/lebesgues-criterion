## Floor 1 — What Was Covered & Understood
- Limits are about approach, not arrival
- L = f(a) — always plug a into the function to find the limit value
- ε controls how close f(x) gets to L (output/y-axis)
- δ controls how close x gets to a (input/x-axis)
- Three rules of continuity: f(a) exists, limit exists, they are equal
- Three types of discontinuity:
  - Removable — rule 3 breaks (f(a) and limit exist but aren't equal)
  - Jump — rule 3 breaks (left and right limits differ so no overall limit)
  - Essential — rule 2 breaks (limit doesn't exist at all)
